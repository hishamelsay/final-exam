Question 1: Complete the following

(10 Marks — 2 Marks for each)
Q1.1 MAC addresses are …… bits in length.
✅ Answer:
MAC addresses are 48 bits in length.
🌍 الترجمة:
عناوين الـ MAC طولها 48 بت.
💡 الشرح بالعامي:
الـ MAC Address ده زي "البصمة" بتاعة كارت الشبكة — كل كارت في الدنيا ليه رقم مميز طوله 48 بت، وبيتكتب في شكل 12 رقم hex زي: AA:BB:CC:DD:EE:FF. ده ثابت ومش بيتغير (عكس الـ IP).
Q1.2 Principle application layer protocol for Internet mail Sent over TCP……
✅ Answer:
Principle application layer protocol for Internet mail Sent over TCP is SMTP (Simple Mail Transfer Protocol).
🌍 الترجمة:
البروتوكول الأساسي لطبقة التطبيقات لإرسال الإيميل عبر الإنترنت باستخدام TCP هو SMTP.
💡 الشرح بالعامي:
الـ SMTP ده البروتوكول اللي بيبعت الإيميلات. لما بتبعت إيميل من Gmail مثلاً، SMTP هو اللي بيشيل الرسالة ويوصّلها. وبيشتغل فوق TCP عشان يضمن الرسالة توصل كاملة.
Q1.3 …… enables the Network layer to pass the data to the appropriate upper-layer protocol.
✅ Answer:
Protocol field (Port numbers) enables the Network layer to pass the data to the appropriate upper-layer protocol.
🌍 الترجمة:
أرقام البورتات (حقل البروتوكول) هي اللي بتخلي طبقة الشبكة توصّل البيانات للبروتوكول المناسب في الطبقة اللي فوقها.
💡 الشرح بالعامي:
تخيل إن البيانات وصلت للطبقة التالتة (Network)، محتاجة تعرف تروح لمين فوق — TCP ولا UDP؟ الـ Protocol field في الـ IP header هو اللي بيقولها "روحي لـ TCP (رقم 6) أو UDP (رقم 17)".
Q1.4 …… was developed to allow for file transfers between a client and a server.
✅ Answer:
FTP (File Transfer Protocol) was developed to allow for file transfers between a client and a server.
🌍 الترجمة:
بروتوكول نقل الملفات (FTP) تم تطويره عشان يسمح بنقل الملفات بين العميل والسيرفر.
💡 الشرح بالعامي:
الـ FTP ده زي "شركة شحن" للملفات — بتستخدمه لما عايز ترفع ملف على سيرفر أو تنزّل ملف منه. بيشتغل على Port 21 وبيستخدم TCP عشان يضمن الملف يوصل كامل.
Q1.5 End devices are referred to as ……
✅ Answer:
End devices are referred to as Hosts.
🌍 الترجمة:
الأجهزة الطرفية بنسمّيها "مضيفات" (Hosts).
💡 الشرح بالعامي:
الـ End Devices دي الأجهزة اللي في آخر الشبكة — يعني الكمبيوتر بتاعك، الموبايل، الطابعة. بنسمّيها Hosts عشان هي اللي "بتستضيف" التطبيقات والبرامج اللي بتستخدم الشبكة.

Q2.1 Process of adding control information as it passes down through the layered model:
✅ a. Encapsulation
b. Decapsulation
💡 بالعامي:
الـ Encapsulation = "تغليف". لما البيانات بتنزل من طبقة لطبقة، كل طبقة بتحط عليها header (معلومات تحكم). زي لما تحط الجواب في ظرف، وبعدين الظرف في صندوق، والصندوق في كرتونة. العكس (الفك) اسمه Decapsulation.
Q2.2 The general term for the PDU used at the Application layer is:
✅ a. Data
b. Segment
c. Bits
💡 بالعامي:
كل طبقة بتسمّي البيانات اسم مختلف (PDU): طبقة Application = Data، Transport = Segment، Network = Packet، Data Link = Frame، Physical = Bits. يعني في أعلى طبقة البيانات بتفضل "Data" عادي.
Q2.3 Protocol which offers an alternate and secure method for server access and Stronger authentication, Encrypts data:
a. DNS
c. TELNET
b. DHCP
✅ d. SSH
💡 بالعامي:
الـ SSH (Secure Shell) = نسخة آمنة من Telnet. الفرق إن SSH بيشفّر البيانات (يعني لو حد قعد يتنصّت مش هيفهم حاجة)، لكن Telnet بيبعت كل حاجة مكشوفة — بما فيها الباسورد!
Q2.4 Consisting of the source and destination IP addresses and port numbers, is also unique and identifies the conversation between the two hosts:
a. Source port number
c. Destination port number
✅ b. Socket pair
💡 بالعامي:
الـ Socket Pair = (IP المصدر + Port المصدر + IP الوجهة + Port الوجهة). ده الكومبو الكامل اللي بيميّز كل "محادثة" بين جهازين. زي ما بتقول: "من شقة 5 عمارة أحمد → لشقة 3 عمارة علي".
Q2.5 A special address used to send data to all hosts in the network:
a. Network address
✅ c. Broadcast address
b. Host address
💡 بالعامي:
الـ Broadcast = "بتنادي على كل الناس في الشبكة مرة واحدة". زي لما حد يفتح الميكروفون في المدرسة ويكلّم كل الطلبة. العنوان ده بيبقى كل الـ host bits فيه = 1 (مثلاً 192.168.1.255).
Q2.6 A network device used to Regenerate signals distorted by transmission loss due to attenuation:
✅ a. Repeater
b. Router
c. Switch
💡 بالعامي:
الـ Repeater = "مكبّر الإشارة". لما الإشارة تمشي مسافة طويلة على السلك بتضعف (attenuation)، الـ Repeater بياخد الإشارة الضعيفة ويقوّيها تاني ويبعتها. زي لما حد يسمع كلمة ويعيد يناديها بصوت أعلى.
Q2.7 The method of representing the bits is called:
✅ a. Signaling
b. Encoding
c. Decoding
💡 بالعامي:
الـ Signaling = "طريقة تمثيل البتات على الكابل". يعني إزاي الصفر والواحد بيتحولوا لإشارة كهربائية أو ضوئية. أما الـ Encoding فده تحويل البيانات لكود معين قبل الإرسال.

Q2.8 Repeater and hub work in:
✅ a. Half duplex mode
b. Full duplex mode
💡 بالعامي:

Q2.9 Protocol can implement a method to ensure reliable delivery of the data:

Q2.10 The number for this communication associated with the originating application on the local host is:
✅ a. Source port number
c. Socket pair
b. Destination port number
💡 بالعامي:

Q4.3 What are the differences between the layers of TCP/IP model and OSI model?
OSI Model — 7 Layers
  • 7. Application
  • 6. Presentation
  • 5. Session
  • 4. Transport
  • 3. Network
  • 2. Data Link
  • 1. Physical
TCP/IP Model — 4 Layers
  • 4. Application (= 7+6+5)
  • 3. Transport (= 4)
  • 2. Internet (= 3)
  • 1. Network Access (= 2+1)
💡 بالعامي:
الـ OSI = 7 طبقات (نموذج نظري للتعليم). الـ TCP/IP = 4 طبقات (النموذج العملي اللي الإنترنت بيشتغل بيه فعلاً). الـ TCP/IP دمج الطبقات 5+6+7 في طبقة واحدة (Application)، ودمج 1+2 في طبقة واحدة (Network Access). يعني TCP/IP أبسط بس OSI أوضح في الشرح.
Q4.4 List Main components of Router:
✅ Answer:
Router consists of two main components:
1. Hardware (Physical components) — Memory types:
  • ROM: Stores startup diagnostic code (POST & Bootstrap program)
  • RAM: Holds the running configuration and routing table
  • NVRAM: Stores the startup configuration file
  • FLASH: Stores full Cisco IOS software images
2. Software — IOS (Internetworking Operating System) + Configuration file
💡 بالعامي:
الراوتر زي الكمبيوتر كده — فيه هاردوير وسوفتوير. الهاردوير فيه 4 أنواع ذاكرة: ROM (بتشغّله أول ما يفتح)، RAM (الإعدادات الحالية)، NVRAM (الإعدادات المحفوظة — مش بتتمسح لما يفصل)، FLASH (نظام التشغيل IOS). والسوفتوير هو نظام IOS بتاع Cisco.
Q4.5 What are the types of IP address?
✅ Answer:
IP address could be one of three categories:
1. Network address: The address by which we refer to the network.
2. Host address: The addresses assigned to the end devices in the network.
3. Broadcast address: A special address used to send data to all hosts in the network.
💡 بالعامي:
Network address = عنوان الشبكة نفسها (زي اسم الشارع). Host address = عنوان الجهاز (زي رقم البيت). Broadcast = بتبعت لكل الأجهزة في الشبكة مرة واحدة (زي ما تنادي على كل الجيران). مثلاً: 192.168.1.0 = الشبكة، 192.168.1.50 = جهاز، 192.168.1.255 = برودكاست.
Q4.6 What are the differences between the classless and classful?
Classless IP Addressing
  • Subnet mask determines network & host portion
  • Value of first octet does NOT matter
  • Uses CIDR notation (e.g. /24)
  • Used in the Internet today
Classful IP Addressing
  • First octet determines network & host portion
  • Fixed classes: A, B, C, D, E
  • Used with classful protocols like RIPv1
  • Older method — wastes IPs
💡 بالعامي:
Classful = النظام القديم — بيقسّم العناوين لفئات (A, B, C) على حسب أول رقم في الـ IP. المشكلة إنه بيضيّع عناوين كتير. Classless = النظام الحديث — بيستخدم الـ Subnet Mask أو الـ CIDR (/24 مثلاً) عشان يقسّم بمرونة أكبر. ده اللي العالم كله بيستخدمه دلوقتي.

2. Improves quality and reliability of the software product.
3. Ensures requirements are met and validates functionality.
4. Reduces costs — finding bugs early is cheaper than fixing them later.

Q4.8 Name some important testing strategies in software engineering:
✅ Answer:
1. Unit Testing: Testing individual components or modules separately.
2. Integration Testing: Testing combined modules to check their interaction.
3. System Testing: Testing the complete integrated system as a whole.
4. Acceptance Testing: Final testing to check if system meets user requirements.
5. Regression Testing: Re-testing after changes to ensure nothing is broken.
💡 بالعامي:
Unit = بتختبر كل جزء لوحده. Integration = بتختبر الأجزاء مع بعض. System = بتختبر النظام كله. Acceptance = العميل بيجرّب ويوافق. Regression = بعد ما تعدّل حاجة بتعيد الاختبار عشان تتأكد إنك مكسرتش حاجة تانية.

📚 ملحق: أهم النقاط من المادة للمراجعة السريعة

مصطلحات + معلومات ممكن تيجي في أسئلة تانية
📦 PDU Names per Layer (مهم جداً):
Application → Data  |  Transport → Segment  |  Network → Packet  |  Data Link → Frame  |  Physical → Bits
💡 بالعامي:
كل طبقة بتسمّي البيانات اسم مختلف. في أعلى طبقة (Application) اسمها Data. لما تنزل Transport بتتقسم لـ Segments. لما تنزل Network بتبقى Packets. لما تنزل Data Link بتبقى Frames. وأخر حاجة Physical بتبقى Bits (أصفار وواحدات).
🏷️ IP Address Classes:
ClassFirst Octet RangeDefault MaskUsage
A1 — 126255.0.0.0 (/8)Large networks
B128 — 191255.255.0.0 (/16)Medium networks
C192 — 223255.255.255.0 (/24)Small networks
D224 — 239N/AMulticasting

💡 بالعامي:
لو أول رقم في الـ IP من 1 لـ 126 = Class A (شبكات ضخمة). من 128 لـ 191 = Class B (متوسطة). من 192 لـ 223 = Class C (صغيرة). D للـ Multicasting و E للتجارب.
🛣️ Routing Protocols:
• RIP: Based on least number of hops (hop count).
• OSPF: Based on speed of hops (bandwidth), not count.
• EIGRP: Based on surrounding conditions (bandwidth, delay, load, reliability).
• BGP: Maintains data security between autonomous systems.
• ARP: Takes IP → sends MAC | RARP: Takes MAC → sends IP.
• ICMP: Controls Internet speed (ping uses this).
💡 بالعامي:
RIP = بيختار أقصر طريق (أقل قفزات). OSPF = بيختار أسرع طريق (مش أقصر). EIGRP = بيختار أحسن طريق بناءً على كل الظروف. ARP = عنده IP وعايز يعرف MAC (زي: عارف العنوان بس مش عارف رقم الشقة).
🔌 Cable Types + Encoding:
• Metallic wires (Copper): Encoding into electrical impulses.
• Fiber optics: Encoding into visible light ranges. Speed: 2-3 Gbps.
• Wireless: Encoding into electromagnetic waves.
• UTP (Unshielded Twisted Pair): 10-100 Mbps, 100m, cheap & easy.
💡 بالعامي:
الأسلاك النحاس بتبعت إشارات كهربية. الفايبر بيبعت ضوء (أسرع حاجة). الوايرلس بيبعت موجات كهرومغناطيسية (زي الراديو). سؤال الامتحان اللي في المادة: نحاس=كهرباء، فايبر=ضوء، وايرلس=موجات.
🚩 TCP 6 Control Flags:
URG Urgent  |  ACK Acknowledgement  |  PSH Push  |  RST Reset  |  SYN Synchronize  |  FIN Finish
💡 بالعامي:
SYN = "ألو، عايز أتكلم". ACK = "أيوا سمعتك". FIN = "خلاص باي". RST = "قفّل الخط فوراً". PSH = "ابعت الداتا فوراً متستناش". URG = "ده مهم أوي شوفه الأول".
🧮 Subnetting Quick Formula:
1. Number of subnets needed = 2n (n = bits borrowed)
2. New subnet mask: Add borrowed bits to default mask.
3. Hop count = 256 – interesting octet value.
Example: 192.168.1.0/24 into 4 subnets → 2² = 4 → mask = /26 = 255.255.255.192 → hop = 256-192 = 64
Subnets: .0, .64, .128, .192
💡 بالعامي:
الـ Subnetting = بتقسّم شبكة كبيرة لشبكات صغيرة. عايز 4 شبكات؟ محتاج 2 بت (2²=4). بتزود 2 بت على الماسك وبتحسب الـ hop: 256 - القيمة الجديدة. الشبكات بتبدأ من 0 وبتقفز بالـ hop count. سهلة لما تتمرّن عليها!
